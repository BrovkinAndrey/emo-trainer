# Emo Trainer

Тестовое задание “Web-программист”. Интерактивный тренажёр для людей с ментальными особенностями.

## Демо

[Посмотреть онлайн](https://brovkinandrey.github.io/emo-trainer/) — если включите GitHub Pages.

## Возможности

- Показ задания с картинкой
- Проверка ответов (регистр не важен)
- Сохранение результатов в `localStorage`
- Демонстрация результатов
- Адаптивный дизайн под мобильные устройства
- Подсветка гласных в результатах

## Стек

- HTML5
- CSS3
- Vanilla JavaScript
- ESLint + @stylistic для проверки кода
